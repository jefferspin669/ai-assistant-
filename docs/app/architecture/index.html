users

Primary identity table (passwords live in user_credentials).

  • id
  • email
  • full_name
  • profile_image
  • timezone
  • preferred_language
  • created_at
  • updated_at

organizations

Business workspace owned by a users.id.

  • id
  • owner_id
  • business_name
  • logo_url
  • business_type
  • tax_structure
  • state
  • created_at

organization_members

Membership join table — role and status per user in an org.

  • id
  • organization_id
  • user_id
  • role
  • status
  • joined_at

calendar_categories

Color labels referenced by calendar_events.category_id.

  • id
  • user_id
  • organization_id
  • name
  • color
  • icon

calendar_events

Scheduled work and life events for a user + organization.

  • id
  • user_id
  • organization_id
  • title
  • description
  • start_time
  • end_time
  • timezone
  • category_id
  • location
  • priority
  • reminder_time
  • recurring_rule
  • external_calendar_id
  • created_at
